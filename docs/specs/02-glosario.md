# 02 · Glosario

| Término | Definición en DinoTV |
|---|---|
| **Canal** | Flujo de emisión continuo con su propia parrilla, logo e identidad visual. |
| **Parrilla** | Programación semanal de un canal: qué se emite, cuándo y por cuánto tiempo. |
| **Franja** | Bloque horario con nombre y estilo propio (p. ej. "Matiné Anime 15:00-18:00"). |
| **Regla de programación** | Patrón recurrente: "Lun-Vie a las 15:00, 2 episodios de *Serie X*". |
| **Slot** | Ocurrencia concreta de una regla en una fecha: "Martes 12, 15:00-16:00". |
| **Materializar** | Convertir reglas + excepciones en una lista exacta de elementos con hora de inicio al segundo. |
| **Elemento de emisión (item)** | Cualquier pieza con duración: episodio, película, promo, cortinilla, anuncio, carta de ajuste. |
| **Serie lineal** | Episodios con continuidad; se emiten en orden estricto mediante un **cursor**. |
| **Serie antológica / episódica** | Episodios independientes; pueden emitirse en orden aleatorio sin repetir hasta agotar el ciclo. |
| **Cursor** | Puntero al próximo episodio a emitir de una serie lineal. |
| **Append** | Agregar nuevos episodios al final de una serie existente sin romper su cursor. |
| **Continuidad** | Material entre programas: promos, cortinillas, IDs del canal, avisos. |
| **Cortinilla (bumper)** | Clip corto de entrada/salida de corte: "Ya volvemos", "Regresamos con…". |
| **ID de canal (ident)** | Animación breve con el logo del canal. |
| **Promo** | Clip que anuncia un programa futuro con día y hora ("Viernes 8 PM"). |
| **"A continuación" (lower third)** | Rótulo superpuesto en el tercio inferior anunciando lo siguiente. |
| **Mosca (DOG)** | Logo semitransparente en una esquina durante la emisión. |
| **Corte comercial** | Pausa dentro de un programa con promos/anuncios del usuario. |
| **Relleno (filler)** | Material usado para completar el tiempo hasta la siguiente hora exacta. |
| **Reprogramación** | Cambio puntual sobre la parrilla materializada (excepción a las reglas). |
| **Estreno / Evento** | Película o especial anclado a un día y hora únicos, con campaña de promos previa. |
| **Carta de ajuste** | Imagen de prueba emitida en "fin de emisión" nocturno. |
| **Playout** | Motor que reproduce en tiempo real la lista materializada. |
| **Incorporación tardía (join-in-progress)** | Al encender, reproducir desde el punto exacto que corresponde a la hora actual. |
| **Modo flexible** | Opción que permite pausar; al reanudar la parrilla se desplaza. |
| **Media Center** | Aplicación de escritorio (PC) con la misma interfaz de TV más herramientas de administración. |
