# DinoTV 🦖📺

Tu propio canal de televisión: tus series y películas emitidas **a horas exactas**, con promos, cortinillas y estrenos, como la TV de antes. Parrilla controlada desde Android.

- **Núcleo**: Go (scheduler + playout con mpv + generador de promos)
- **Control**: App Android en Kotlin (Jetpack Compose)
- **Pantallas**: interfaz de TV y Media Center con estética tipo Wii U
- **Etapas**: Beta → Final
